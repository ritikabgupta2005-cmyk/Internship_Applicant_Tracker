# Internship Applicant Tracker 📝

## 📌 Project Overview

The Internship Applicant Tracker is a Python-based project that helps manage internship applications. It allows users to store applicant details, track application statuses, and analyze internship stipends using a simple menu-driven program.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook

## ✨ Key Features

* Display all internship applications.
* Add new internship applications.
* Search applications by company name.
* Filter applications by status.
* Update application status.
* Find the highest internship stipend.
* Calculate the average stipend.
* Count applications by status.
* Delete an application.

## 📚 Python Concepts Used

* Classes and Objects
* Functions
* Lists and Loops
* Conditional Statements
* User Input
* Basic Data Analysis


## 🎯 Project Objective

The objective of this project is to practice Python programming by building a simple application management system that organizes internship details and tracks application progress.

## 💡 Key Learnings

* Learned to use classes and objects.
* Practiced creating and calling functions.
* Managed data using lists and objects.
* Implemented searching, filtering, updating, and deleting operations.
* Used basic calculations to analyze stipend information.
